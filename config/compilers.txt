# psp-gcc version (DW_AT_producer / .comment) -> cc1 in tmp/toolchains/bin,
# then the options the psp-gcc driver of that version passes to cc1, and
# (as:OPT) options that make the 1.3.1 psp-as behave like that version's
# assembler: from 1.6.1 on (no -mno-ulsw), lwl/lwr are accepted and ulw/usw expand to
# lwl/lwr and swl/swr instead of byte loads and stores.
# (mixed:OPT) options only for units that still include asm: with
# -fno-merge-constants the C float constants stay in .rodata in emission
# order next to the asm's, as one .rodata.cst4 section per object would not.
# (lib:OPT) options only for newlib/libgcc/libstdc++ units.  (objorder) the
# app units' .rodata and .rodata.cst* sections link in object order.
# (locfix) built with -g and assembled by a psp-as that does not move an
# instruction into a branch delay slot across a source line change
# (tools/locfix.py); newlib:locfix for the newlib units only: only 1.6.1's
# psp-newlib has such line tables (a DW_LNE_set_address for every row).
# Versions we have no reconstruction of use the nearest one we do.
# 1.9.2 (gcc-3.3.6 based) uses the Allegrex 3.1 register ext/ins without
# being asked: its newlib, libgcc and the SDK's libgim_picture (whose
# Makefile has no -mext) need -mext.
1.3.1           1.3.1-orig -mno-ulsw
1.4.0           1.3.1-orig -mno-ulsw
1.4.0.internal  1.3.1-orig -mno-ulsw
1.5.0.internal  1.3.1-orig -mno-ulsw
1.5.1           1.5.1   -mno-ulsw
1.5.1.internal  1.5.1   -mno-ulsw objorder
1.6.1           1.6.1   newlib:locfix as:-mulsw
1.6.1.internal  1.6.1   newlib:locfix lib:-fno-merge-constants mixed:-fno-merge-constants objorder as:-mulsw
1.7.1           1.7.1-orig as:-mulsw
1.8.3           1.8.3   as:-mulsw
1.8.3.internal  1.8.3   as:-mulsw
1.8.4.internal  1.8.4   mixed:-fno-merge-constants as:-mulsw
1.9.2           1.9.2   -mext newlib:locfix as:-mulsw
1.9.2.internal  1.9.2   -mext as:-mulsw
# 1.11.0 (gcc-3.3.6, navi's libraries): 1.9.2 with the VFPU vector registers
# no longer fixed (FINDINGS.md); its newlib libm is a locfix build too.  The
# newer internal compilers are unreconstructed: nearest is 1.11.0.
1.11.0          1.11.0  -mext newlib:locfix as:-mulsw
1.12.1.internal 1.11.0  -mext as:-mulsw
1.13.0.internal 1.11.0  -mext as:-mulsw
